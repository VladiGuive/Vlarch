Vlarch

Just, Vlad's Arch

Vlarch is a personal Arch Linux flavor. It is installed in one command from a fresh Arch Linux live ISO.

Install

Boot the live ISO, get networking, then:

curl -fsSL 'https://vlarch.vladi.tech/install.sh' | bash

Optional flags:

curl -fsSL 'https://vlarch.vladi.tech/install.sh' | bash -s -- --dry-run --verbose

What it does

  • Detects ethernet vs WiFi and prompts for credentials when needed
  • Picks timezone, locale, target disk through an fzf TUI
  • Partitions the disk, encrypts root with LUKS1, sets up btrfs subvolumes
  • Installs the Vlarch package set and applies dotfiles
  • Configures GRUB so a single passphrase at boot unlocks the system
  • Boots straight into autologin and Hyprland

Live USB note

The Arch live ISO keeps writable state on a RAM-backed overlay at /run/archiso/cowspace. If RAM is tight, append cow_spacesize=75% at the GRUB boot prompt. The installer's preflight step also remounts cowspace to 75% automatically when free space is low.
