Vlarch

Just, Vlad's Arch

A personal Arch Linux flavor — one command from a fresh Arch Linux live ISO. Install lays down the base; vlarch update brings the desktop.

LUKS + btrfs Hyprland yay

Install

Boot the live ISO, get networking, then:

One-liner curl -fsSL 'https://vlarch.vladi.tech/install.sh' | bash Optional flags curl -fsSL 'https://vlarch.vladi.tech/install.sh' | bash -s -- --dry-run --verbose

Update

On an installed system:

CLI vlarch update Without the CLI curl -fsSL 'https://vlarch.vladi.tech/update.sh' | bash Optional flags vlarch update --dry-run --verbose --force

What it does

  • Detects ethernet vs WiFi and prompts for credentials when needed
  • Picks timezone, locale, and target disk through an fzf TUI
  • Partitions the disk, encrypts root with LUKS, sets up btrfs subvolumes
  • Installs a minimal base, bootstraps yay, and arms first-boot update
  • On first login: networking, full package sync, dotfiles, Hyprland
  • Configures GRUB so one passphrase at boot unlocks the system

Live USB note

The Arch live ISO keeps writable state on a RAM-backed overlay at /run/archiso/cowspace. If RAM is tight, append cow_spacesize=75% at the GRUB boot prompt. The installer's preflight step also remounts cowspace to 75% automatically when free space is low.
